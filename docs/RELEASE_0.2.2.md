# Navigation AI 0.2.2 — 17 октября 2026

Кандидат для Minecraft 26.2 / Fabric Loader 0.19.5 / Fabric API 0.161.0+26.2 /
Java 25. Сопутствующий мод Autonomous Villages 0.2.2 зависит от этой версии.

## Изменения

- `NavigationTask` и `ExcavationTask` предоставляют накопленные
  `infrastructureWaitTicks()`. Это ожидание инфраструктуры, а не время самой
  игровой работы. `InfrastructureWaitAccounting` сохраняет вклад заменённых
  дочерних задач и сбрасывается при смене задания.
- `InfrastructureWaitTracker` считает ожидание в игровых тиках, сохраняя
  независимый реальный предел 30 секунд для незавершённого ожидания.
- `TickWorkBudget` рассчитывает CPU-бюджеты от целевого интервала тика и
  фактического времени обработки. Проверки угроз сохраняют интервал в тиках.
- Runtime/навигация/проходка подключены к этим бюджетам и счётчикам, чтобы
  ускоренная симуляция не расходовала игровой срок на ожидание инфраструктуры.

400 TPS — ориентир, измеренный ранее на конкретной машине, а не результат
приёмки 0.2.2. Новые измерения, игровой запуск и модульные тесты не выполняются
по прямому указанию пользователя. Существующие тестовые исходники сохраняются
в репозитории; их наличие не означает, что они запускались на этом кандидате.

## Контракт инвентаря

`BotInventory.insert`, `extract`, `select` и `equip` заменяют текущий intent;
`transferTo` останавливает intents обоих ботов. Потребитель обязан обеспечить
физическую досягаемость и согласовать момент обмена с состоянием участников.
Этот контракт в 0.2.2 не изменён. Autonomous Villages проверяет свободную границу
действий перед назначением и непосредственно перед внешним обменом.

## Сборка

```text
gradlew.bat build -x test --offline --no-daemon
gradlew.bat --stop
```

Файлы: `build/libs/navigation-ai-0.2.2.jar` и
`build/libs/navigation-ai-0.2.2-sources.jar`. Упаковка пары модов выполняется
из соседнего AutonomousVillages через `bundleDistribution` с исключением
test tasks обоих проектов. Контрольные суммы включены в манифест комплекта.
