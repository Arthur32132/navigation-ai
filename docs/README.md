# Документация Navigation AI

Документация соответствует исходникам проекта и артефакту `0.1.0` для Minecraft 26.2.

| Документ | Для чего нужен |
| --- | --- |
| [API](API.md) | Интерфейсы ботов, навигации, задач и политик |
| [Интеграция](INTEGRATION.md) | Подключение библиотеки из другого серверного мода |
| [Архитектура](ARCHITECTURE.md) | Жизненный цикл fake-player, снимки мира и worker-потоки |
| [Сборка](BUILDING.md) | Требования, команды Gradle и публикация JAR |
| [Ограничения](LIMITATIONS.md) | Что реализовано, что пока является заделом и порядок развития |

Публичный API находится в `dev.navigationai.api`. Классы из `dev.navigationai.runtime` и `dev.navigationai.navigation` являются внутренней реализацией и не должны использоваться модами-потребителями напрямую.
