# Security

Navigation AI is experimental, with no supported stable release or promised
security response time. State the exact commit and Minecraft/Fabric/Java
versions when reporting a problem.

Report exploitable vulnerabilities, credentials and private player data using
[GitHub private vulnerability reporting](https://github.com/Arthur32132/navigation-ai/security/advisories/new).
Do not disclose exploits or sensitive information in public issues or PRs.
Include minimal reproduction steps in a disposable world, impact and redacted
evidence. Ordinary bugs belong in public issues.
